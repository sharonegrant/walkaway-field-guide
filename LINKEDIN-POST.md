# LinkedIn launch draft

I wanted an AI coding workflow I could trust while I stepped away from the
keyboard.

So I tested the idea instead of just publishing the setup.

The result is **Walkaway**: my field guide for combining spec-driven
development, bounded orchestration, measured token budgets, and independent
verification.

The first restricted Codex pilot completed two different synthetic jobs in
disposable worktrees:

- 35/35 automated and adversarial checks passed
- 63,125 mean token units per accepted job
- 25% of the budget protected for verification
- no networked commands, GitHub remote, credentials, merge, deployment, or
  production data

The most important lesson: an agent saying “complete” is not proof. Tests,
exact-path policy, secret scans, and a separate verifier have to agree.

I also documented what the first draft got wrong—including an unsafe backend
route I excluded, outdated configuration keys, and why a nominal token cap is
not the same as a provider-enforced spending limit.

I’m publishing the revised guide and honest pilot results so other builders can
learn from both the pattern and its boundaries.

For builders who want to inspect the architecture, the field guide is public on
GitHub. For organizations that want the outcome without assembling the stack,
Rick and I help teams design practical AI, data, dashboard, and workflow systems
through Everyday AI Playbook. Start with an Everyday AI Readiness Audit:
